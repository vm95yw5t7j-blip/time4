# MVP Tasks

## Done In This Scaffold

- Shared data model.
- Free plan preset policy.
- Timer engine based on end date.
- iPhone preset list and editor.
- iPhone 2x2 timer selection.
- iPhone one-tap timer start.
- iPhone running timer screen with progress, pause, resume, stop, +30, and -30.
- iPhone local notification scheduling.
- iPhone running timer persistence.
- Watch preset list.
- Watch 2x2 timer selection.
- Watch running timer screen.
- WatchConnectivity snapshot codec and controllers.
- StoreKit product ID placeholder.
- Running timer execution device field.

## Required Before App Store

- Validate StoreKit 2 purchase and restore flow with the local StoreKit config and App Store Connect product.
- Add App Group suite identifiers if sharing local data directly between targets.
- Add notification permission request UX.
- Verify WatchConnectivity on paired simulator and real Apple Watch.
- Verify background behavior and wrist-down behavior on real Apple Watch.
- Verify iPhone timer local notification behavior after app backgrounding and force quit.
- Add app icons, privacy manifest, App Store screenshots, and metadata.
- Set real bundle identifiers and Apple Developer Team ID.
- Confirm Japanese copy and pricing in App Store Connect.

## Not In MVP

- Sequence timer.
- Multiple simultaneous timers.
- Full realtime running timer sync between iPhone and Apple Watch.
- Normal number-input timer.
- Live Activity.
- Complications.
- Smart Stack.
- Siri and App Intents.
